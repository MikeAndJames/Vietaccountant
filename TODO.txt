Follow these simple steps to deploy:

--------------------------------------------------------------------
STEP 1: Push to GitHub
--------------------------------------------------------------------
In terminal inside the cataccountants folder, run:
   git init
   git add .
   git commit -m "Launch Anh Dao Carrick ACCA website"
   git branch -M main
   git remote add origin https://github.com/MikeAndJames/Vietaccountant.git
   git push -u origin main

--------------------------------------------------------------------
STEP 2: Deploy to Vercel (majic2)
--------------------------------------------------------------------
1. Log into Vercel: https://vercel.com/majic2
2. Click "Add New..." -> "Project"
3. Import "Vietaccountant" repo and click "Deploy"
4. Done! Your preview link (e.g. vietaccountant.vercel.app) is instantly live.

--------------------------------------------------------------------
STEP 3: Connect Custom Domain in GoDaddy
--------------------------------------------------------------------
1. In GoDaddy DNS Management for your domain:
2. Add/Edit the A record:
   - Type: A
   - Name: @
   - Value: 76.76.21.21
   - TTL: 1 Hour
3. Add/Edit the CNAME record:
   - Type: CNAME
   - Name: www
   - Value: cname.vercel-dns.com
   - TTL: 1 Hour
4. In Vercel Project -> Settings -> Domains -> Add domain & www.
